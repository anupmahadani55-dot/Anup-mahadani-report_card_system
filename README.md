Description of Student Report Card System 

This is a small Python project made to calculate results for BCA 4th semester students. It covers 5 subjects — Computer Graphics & Multimedia, Operating System, Software Engineering, Optimization Techniques, and Mathematics 3.

In this program, the user can enter a student's name along with their marks in all 5 subjects. The program then automatically calculates the total marks, percentage, and grade (A, B, C, D, or F).

All student details are stored in a list, where each student is saved as a dictionary containing their name, marks, total, percentage, and grade. The marks are kept in a tuple since they shouldn't change once entered.

Apart from adding students, the program also lets you view all students, search for a particular student by name, and find out who the topper of the batch is. There's a menu that keeps running until the user chooses to exit.

This project uses basic Python concepts like lists, dictionaries, tuples, functions, loops, and if-else conditions.
